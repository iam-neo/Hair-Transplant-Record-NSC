# Roles and permissions

- **Super Admin**: unrestricted (`*`), including system configuration.
- **Admin**: all core clinic workflow and user-management operations, except system-level privileges.
- **Doctor**: patient, clinical, procedure, photo, follow-up, and authorised payment/document operations.
- **Assistant**: permitted registration, photo upload, procedure assistance, assigned follow-ups, and documents.
- **Reception**: basic patient/contact access, follow-up visibility, and authorised payment recording.

Use individual permissions for exceptions; do not change a role solely to grant a one-off privilege.
